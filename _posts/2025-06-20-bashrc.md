업무 특성 상 bash shell을 많이 사용한다. 이 때 평소에 많이 사용하는 명령어들을 hash의 alias 기능으로 단축키로 만들어 사용하는 게 대단히 유용하다[^1]. 이게 생산성에 얼마나 도움이 되겠나 하는 생각이 들겠지만 익숙해지면 생각보다 (진짜로) 괜찮으니 꼭 적용해서 사용해보자.

아래는 본인이 주로 사용하는 단축키이다. 리눅스 계정의 ~/.bashrc에 아래 형식으로 단축키를 설정해놓고 사용하면 된다.

특히 rm, cp, mv 명령어에 -i 옵션은 반드시 달아주자. -i 옵션을 달아야 '정말 덮어 쓰시겠습니까?' 혹은 '정말 삭제하시겠습니까?' 하는 프롬프트가 뜨기 때문에, 실수를 미연에 방지할 수 있다.
```bash
$ vi ~/.bashrc
# 아래와 같은 형식으로 단축키 설정한 뒤, 파일 저장
alias ll='ls -alF'
alias l='ls -CF'
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'
alias q='cd ..'
alias qq='cd ../..'
alias qqq='cd ../../..'
alias gst='git status'
alias gdf='git diff'
alias glg='git log'
$ source ~/.bashrc # 현재 bash shell에도 적용
                   # 이후 새로 실행되는 bash shell에는 자동 적용된다.
```
