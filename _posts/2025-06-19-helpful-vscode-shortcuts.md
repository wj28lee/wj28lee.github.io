Source: [Visual Studio Code Keyboard shortcuts for Winds](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)
- Ctrl+G: Go to line...
- Ctrl+P: Go to file...
- Ctrl+`: Show integrated terminal
- Ctrl+,: User settings
- Ctrl+F4: Close editor
- Alt+<#>: Open a file by number
- F12: Go to definition
- Ctrl+Shift+P: Show command palette
- Ctrl+B: Toggle sidebar visibility
